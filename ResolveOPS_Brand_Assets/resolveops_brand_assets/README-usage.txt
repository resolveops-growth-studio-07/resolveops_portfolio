ResolveOPS Growth Studio — Brand Assets

Brand palette
- Background / near-black: #050711
- Cyan: #00D8F5
- Blue: #1F69FF
- Violet: #7E2CFF
- White: #F7F9FF
- Muted text: #97A3BA

Files
- resolveops-logo-horizontal-dark.png: primary website header logo (transparent background; best on dark sections).
- resolveops-logo-stacked-dark.png: stacked brand logo for footer/cover graphics.
- resolveops-icon-only.png: transparent symbol-only mark (no text).
- favicon.ico / favicon.png / favicon-32.png / favicon-64.png: website tab icons.
- apple-touch-icon.png: iOS home-screen icon.
- pwa-icon-192.png: PWA/app icon.
- instagram-profile-1080.png: Instagram profile image; symbol-only with padding for circular crop.
- website-social-preview-1200x630.png: Open Graph/social share preview image.

Website usage suggestions
- Header: resolveops-logo-horizontal-dark.png on a dark background.
- Mobile header or footer: resolveops-icon-only.png or the horizontal logo if there is enough width.
- Browser tab: favicon.ico (also include favicon.png as a fallback).
- Social preview: set website-social-preview-1200x630.png as og:image.
- Instagram profile: upload instagram-profile-1080.png.

Note: These are raster PNG assets designed for the supplied dark cyan/blue/violet identity. Keep the transparent logos on dark surfaces so their white details stay visible. Review the assets at their actual display size before publishing.

- website-public/: files named and ready to copy into a React/Vite public/ folder, plus HTML meta tag setup and CSS color variables.
